# ContrataTech

Site institucional da **ContrataTech**, equipe de desenvolvedores web (projeto de TCC) que cria sites e experiências digitais para marcas.

## 👥 Equipe

Marco Júnior · Isabella Ferraz · Cauã Alves · Samuel Nascimento · Daniel Martins

## 📄 Conteúdo

- Página inicial com o lema *"Uma marca presente é uma marca otimizada"*
- **Sobre Nós** e **Colaboradores**
- **Páginas individuais** de cada integrante (`Pages/`), cada uma com seu próprio estilo

## 🗂️ Estrutura

```
├── Imagens/        # logo e fotos da equipe
├── JavaScript/     # home.js
├── Pages/          # páginas de cada integrante
└── (HTML/CSS da página inicial)
```

## 🛠️ Tecnologias

HTML · CSS · JavaScript

## 🚀 Como usar

Abra a página inicial no navegador ou publique em hospedagem estática.
